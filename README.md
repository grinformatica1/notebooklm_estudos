Engenharia de Prompts

Durante o estudo, foram realizados testes com diferentes estruturas de prompts para extrair respostas mais profundas sobre comportamento financeiro, inteligência emocional e hábitos financeiros.

As interações buscaram:

aprofundamento psicológico;
aplicação prática;
autoconhecimento financeiro;
identificação de padrões emocionais;
estratégias de autocontrole financeiro.
Exemplos de perguntas utilizadas
"Quais os principais pontos que preciso saber para me controlar melhor financeiramente?"
"Como identificar meus gatilhos emocionais para evitar gastos por impulso?"
"O que são vieses cognitivos e como eles afetam minhas escolhas?"
"Quais estratégias ajudam a evitar compras por impulso?"
"Quais erros impedem as pessoas de prosperarem financeiramente?"
